# 任务台账

本文档是四文档唯一事实来源体系的一部分（另见 `docs/00_REQUIREMENTS.md`、`docs/01_ARCHITECTURE.md`、`docs/02_DECISIONS.md`），记录由架构与审查代理拆分出的实现任务。实现代理应按任务 ID 创建 `docs/IMPLEMENTATION_PLAN.md`，获得批准后再修改代码。

## 状态说明

- 待计划：尚未提交实现计划。
- 计划审查中：实现计划已提交，等待架构与审查代理批准。
- 实施计划已批准：计划已批准，可以实现。
- 已实施待审批：实现完成，等待代码审查。
- 已完成：代码审查通过。
- 暂缓：当前不进入实现。

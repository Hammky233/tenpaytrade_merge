## 一、准备工作：获取文件

### 方式 1：从 GitHub 下载（推荐）

1. 打开浏览器，访问仓库的 **Actions** 页面
2. 找到最新一次绿色 ✓ 的构建记录，点进去
3. 在页面底部 **Artifacts** 区域，点击 `tenpaytrade-linux` 下载
4. 将下载的 `.zip` 文件解压，得到两个文件：
   - `tenpaytrade` — 单批次清洗工具
   - `tenpaytrade-merge` — 多批次合并工具

### 方式 2：通过 U 盘 / 内网传输

同事传给你的话，确认收到这两个文件：

```
tenpaytrade          （大约 30-50 MB）
tenpaytrade-merge    （大约 30-50 MB）
```

---

## 二、第一步：让文件变成可执行

### 2.1 打开终端

- **Ubuntu**：按 `Ctrl + Alt + T`
- **其他发行版**：在应用菜单搜索"终端"或"Terminal"

### 2.2 进入文件所在目录

假设文件放在"下载"文件夹：

```bash
cd ~/下载
```

> **提示**：输入 `ls` 回车，应该能看到 `tenpaytrade` 和 `tenpaytrade-merge` 两个文件。

### 2.3 赋予执行权限（只需做一次）

```bash
chmod +x tenpaytrade tenpaytrade-merge
```

> **说明**：这条命令告诉系统"这两个文件可以运行"。没有报错就是成功了。

### 2.4 验证是否可用

```bash
./tenpaytrade --help
```

如果看到一屏帮助信息（`-s`、`-o` 等参数说明），说明工具已经可以正常使用了。

## 三、功能 A：单批次清洗（最常用）

### 这是什么？

把包含 `TenpayTrades.txt` 的文件夹**整个目录树**扫描一遍，清洗转换后输出一个 Excel 文件。

### 数据目录长什么样？

你的数据源文件夹应该是一个完整的目录树，像这样：

```
案件数据/
├── 张三/
│   ├── wxid_abc123/
│   │   └── TenpayTrades.txt      ← 交易数据文件
│   └── wxid_def456/
│       └── TenpayTrades.txt
├── 李四/
│   └── wwwwbbb/
│       └── TenpayTrades.txt
└── ...
```

> **关键**：文件夹嵌套层级不限制，工具会自动递归搜索所有名叫 `TenpayTrades.txt` 的文件。

### 运行命令

```bash
./tenpaytrade -s 数据源文件夹路径 -o 输出文件夹路径
```

### 实际例子

假设你的数据在 `/home/zhangsan/桌面/案件数据`，想把结果输出到 `/home/zhangsan/桌面/结果`：

```bash
# 先创建输出文件夹（如果还不存在）
mkdir -p ~/桌面/结果

# 运行清洗
./tenpaytrade -s ~/桌面/案件数据 -o ~/桌面/结果
```

### 自定义输出文件名

默认输出文件名为 `Tenpay_merge.xlsx`。如果你想自己命名：

```bash
./tenpaytrade -s ~/桌面/案件数据 -o ~/桌面/结果 -n 2026年6月交易汇总.xlsx
```

### 运行过程

运行时会打印类似以下的日志：

```
[09:25:17] 找到 23 个 TenpayTrades.txt 文件
[09:25:17] ✔ .../张三/wxid_abc/TenpayTrades.txt (196 行)
[09:25:17] ✔ .../李四/wwbb/TenpayTrades.txt (478 行)
...
[09:25:18] 合并: 14 个文件 → 2981 行
[09:25:18] 去重: 2981 → 2941 (移除 40 条重复)
[09:25:18] 停车缴费记录: 135 条
[09:25:19] Excel 输出完成
```

最后打印摘要：

```
============================================================
处理完成!
  文件总数: 23
  成功: 14
  失败: 0
  跳过: 9
  总记录: 2941 行
  输出文件: /home/zhangsan/桌面/结果/Tenpay_merge.xlsx
  耗时: 1.8 秒
============================================================
```

## 四、功能 B：多批次合并

### 这是什么？

**同一个案件**分多次导出、分别清洗后，把多个 Excel 合并成一个，并自动去重。

> **使用场景**：比如你 6 月 5 日导出清洗了一次，6 月 7 日又导出清洗了一次，现在想把两次结果合成一份。

### 运行命令

```bash
./tenpaytrade-merge -i 第一批.xlsx 第二批.xlsx 第三批.xlsx -o 合并结果.xlsx
```

### 实际例子

```bash
./tenpaytrade-merge \
  -i ~/桌面/结果/batch_0605.xlsx ~/桌面/结果/batch_0607.xlsx \
  -o ~/桌面/结果/合并_0605_0607.xlsx
```

> **注意**：`-i` 后面可以跟任意多个文件（至少 1 个），用空格分隔。

## 五、输出结果说明

输出的 Excel 文件包含 **1~3 个工作表**（Sheet）：

| 工作表名 | 说明 |
|---------|------|
| **财付通交易汇总** | 全部交易记录（已清洗、去重） |
| **停车缴费** | 自动识别出的停车缴费记录（如果有的话） |
| **特殊交易** | 情感数字、特殊日期、特殊备注记录（如果有的话） |

### 汇总表包含的关键列

| 列名 | 说明 |
|------|------|
| 日期 | 交易日期（如 `2026/4/2`） |
| 时间 | 交易时间（如 `14:30:25`） |
| 时段 | 自动分类：凌晨/早上/下午/晚上 |
| 日期分类 | 自动分类：工作日/周末/节假日（春节） |
| 交易金额(元) | 已从"分"转换为"元" |
| 进账金额 / 出账金额 | 按借贷方向拆分 |
| 交易用途类型 | 交易类型说明 |
| 备注1 / 备注2 | 原始备注信息 |

> 部分敏感列（交易单号、银行卡号等）默认隐藏，如需查看请在 Excel 中右键取消隐藏。

## 六、常见问题排查

### Q1：运行 `./tenpaytrade` 提示"权限不够"（Permission denied）

```bash
chmod +x tenpaytrade
```

然后再试。

---

### Q2：运行后提示"无法执行二进制文件"（cannot execute binary file）

可能原因：
- **下载了错误的文件**：确认你下载的是 `tenpaytrade-linux.zip`（不是 Windows 的 `.exe`）
- **系统架构不匹配**：该文件在 x86_64（Intel/AMD 64 位）Linux 上构建，ARM（树莓派、Apple M 芯片 Linux）不兼容。确认系统：`uname -m` 应该输出 `x86_64`

---

### Q3：提示"未找到任何 TenpayTrades.txt 文件"

检查数据源路径是否正确。确认：
```bash
# 列出文件夹内容，看看里面有什么
ls -R 你的数据源文件夹 | grep TenpayTrades.txt
```
如果没有输出，说明该文件夹下确实没有 `TenpayTrades.txt` 文件（或者文件名不完全一致，注意大小写）。

---

### Q4：输出的 Excel 打开后中文是乱码

这通常是 Excel 版本问题，不是工具的问题。尝试：
- **LibreOffice**：直接打开通常没问题
- **WPS Office Linux 版**：直接打开
- **Microsoft Excel（Wine）**：数据 → 从文本导入 → 选择 UTF-8 编码

如果必须用 Excel 打开，可以在 Windows 电脑上打开查看。

---

### Q5：处理到一半报错退出

查看错误信息中的文件名，常见原因：
- 某个 `TenpayTrades.txt` 文件损坏或格式异常 → 检查该文件内容
- 磁盘空间不足 → `df -h` 查看剩余空间
- 输出目录没有写入权限 → 换一个有权限的目录

---

### Q6：文件太大，运行很慢怎么办？

- 几十万行数据通常在 **2-3 秒内**完成
- 上百万行数据可能需要 10-20 秒
- 如果超过 1 分钟仍未完成，可能是磁盘 I/O 瓶颈（机械硬盘 + 大量小文件），等待即可

---

### Q7：能在没有图形界面的服务器上运行吗？

可以。这两个工具都是**纯命令行**的，不需要桌面环境。通过 SSH 远程登录服务器即可使用。

---

### Q8：不想每次输入那么长的路径

可以把工具放到系统路径中：

```bash
# 移动到 /usr/local/bin（需要 sudo 权限）
sudo cp tenpaytrade tenpaytrade-merge /usr/local/bin/

# 之后在任何目录都能直接运行
tenpaytrade -s 数据目录 -o 输出目录
tenpaytrade-merge -i a.xlsx b.xlsx -o merged.xlsx
```
